Masukkan URL CSV di atas lalu klik "Muat data".
Cara dapat URL CSV: buka tiap tab (Hasil / Keyword / Bio) di sheet, lihat #gid=... di address bar, lalu pakai https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/export?format=csv&gid=GID (gid beda per tab, jadi URL tidak akan tertukar sama). Alternatif: File → Share → Publish to web — pastikan dropdown sheet diganti sebelum publish ulang, atau tab bisa menghasilkan link yang sama.
Menjalankan scraping (termasuk bio) dilakukan dari tab Actions di GitHub repo, bukan dari halaman ini.
